# 古平町観光協会ウェブサイト

北海道古平町の観光情報を提供する公式ウェブサイトです。

## プロジェクト概要

このプロジェクトは、Next.js 14のApp Routerを使用して構築された古平町観光協会の公式ウェブサイトです。訪問者に観光スポット、宿泊施設、飲食店、イベント情報などを提供し、町の魅力を発信します。

## 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **スタイリング**: Tailwind CSS
- **UIコンポーネント**: shadcn/ui
- **アイコン**: Lucide React
- **画像最適化**: Next.js Image
- **アニメーション**: カスタムFlameParticlesコンポーネント
- **カルーセル**: Embla Carousel
