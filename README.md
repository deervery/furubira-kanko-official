# 古平町観光協会ウェブサイト

北海道古平町の観光情報を提供する公式ウェブサイトです。

## プロジェクト概要

このプロジェクトは、Next.js 14のApp Routerを使用して構築された古平町観光協会の公式ウェブサイトです。訪問者に観光スポット、宿泊施設、飲食店、イベント情報などを提供し、町の魅力を発信します。

## 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **スタイリング**: Tailwind CSS
- **UIコンポーネント**: shadcn/ui
- **アイコン**: Lucide React
- **画像最適化**: Next.js Image
- **アニメーション**: カスタムFlameParticlesコンポーネント
- **カルーセル**: Embla Carousel

## 要開発な作業

### furubira_infoテーブルへの継続的な情報投入バッチ処理機構

**目的**: `furubira_info`テーブルに継続的に情報を自動投入するバッチ処理システムを構築する。

**現状**:
- 手動実行スクリプト（`scripts/ingest-furubira-info.mjs`、`scripts/update-furubira-info.mjs`）は存在するが、自動実行機構がない
- RAG（埋め込み検索）で使用される`furubira_info`テーブルのデータを定期的に更新する必要がある

**要件**:
1. **スケジューリング機能**
   - 定期的な自動実行（例: 毎日、毎週など）
   - Vercel Cron Jobs、GitHub Actions、またはその他のスケジューラーとの統合

2. **データソース対応**
   - JSONファイル（`scripts/furubira_content.json`など）からの読み込み
   - 将来的には外部APIやCMSからのデータ取得にも対応可能な設計

3. **エラーハンドリングとログ記録**
   - バッチ処理の実行ログの記録
   - エラー発生時の通知機能（メール、Slackなど）
   - リトライ機構

4. **差分更新の最適化**
   - 既存の`content_hash`ベースの差分更新ロジックを活用
   - 不要データの自動削除オプション

5. **監視と管理**
   - バッチ処理の実行状況を確認できるダッシュボードまたはログビューア
   - 手動実行も可能な管理画面（オプション）

**技術的な検討事項**:
- Next.js API Routesでのバッチ処理エンドポイント作成
- Vercel Cron Jobsの設定（`vercel.json`または`app/api/cron/`）
- 環境変数による設定管理（実行頻度、データソースパスなど）
- 既存の`scripts/ingest-furubira-info.mjs`のロジックを再利用
