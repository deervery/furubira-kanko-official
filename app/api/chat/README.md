# ふるびら AI ガイド

## 概要

本プロジェクトは、古平町向けの特化型 AI ガイドを提供するシステムです。  
大きく分けて **RAG (Retrieval-Augmented Generation)** と **ICL (In-Context Learning)** の 2 つのアプローチを実装しています。

## 実装の選択と課題

### ICL（In-Context Learning）

- RAG 方式では類似度判定の精度が低く、見当違いの回答が生じることがあったため、ICL を採用しました。
- ICL ではシステムプロンプト内に情報を含めることで、より一貫性のある応答が可能です。
- ただし、トークン数が増加しやすいため、**費用が高くなる** 可能性があります。

### RAG（Retrieval-Augmented Generation）

- Supabase を利用し、埋め込みベクトルを用いた検索を行います。
- 過去の試験では、RAG の類似度検索が期待通りの精度を示さなかったため、ICL へ移行しました。
- ただし、**npm の`ai`パッケージを使用したストリーミングの影響** で RAG の動作がうまくいかなかった可能性もあり、要テスト。

## 今後の検討

- **RAG (Supabase) × gpt-4o** と **ICL (gpt-4o-mini)** の品質とコストを比較し、最適な方式を決定する。
- `ai`パッケージを使ったストリーミングが適切に機能しない原因の特定と解決。

## 連携技術

- **Supabase**（データベース、埋め込み検索）
- **OpenAI GPT-4o / GPT-4o-mini**（AI モデル）
- **Next.js API**（チャットエンドポイント）
- **npm `ai`**（ストリーミング処理）
